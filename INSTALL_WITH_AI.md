# Промпт для установки с помощью ИИ-агента

Скопируйте текст ниже в агента, открытого в корне клонированного репозитория.

---

Ты устанавливаешь Token Counter для OpenCode из текущего клона. Найди корень по
`AGENTS.md` и `pyproject.toml`; не предполагай имя диска, каталога или пользователя.
Прочитай `AGENTS.md`, `README.md` и `docs/connection.md`.

Цель: создать `.venv` и runtime внутри корня, запустить сервис на
`127.0.0.1:8001`, а затем обратимо подключить совместимый OpenCode provider
`bifrost-litellm` вместе с Session ID plugin. Этот промпт разрешает локальную
установку и штатное подключение OpenCode. Он не разрешает реальную генерацию,
изменение моделей, лимитов, MCP, gateway, пользовательских секретов или бинарников
OpenCode Desktop.

1. Проверь OS, Python >= 3.12, свободен ли порт 8001, наличие OpenCode config в
   `~/.config/opencode/opencode.json` и наличие переменной API key, на которую он
   ссылается. Значение ключа не выводи.
2. Если OpenCode уже указывает на счётчик из другой копии проекта, разреши
   установщику выполнить встроенную миграцию только после проверки прежних
   connection-plan, env, client.key и plugin. Он должен сохранить значение
   локального client key, не выводя его, и обновить только проверенный plugin с
   возможностью восстановить его прежнюю версию. При несовпадении остановись и
   используй штатный rollback из прежней копии. Сохрани её БД через backup.
3. На Windows выполни из корня:
   `powershell -ExecutionPolicy Bypass -File scripts/install.ps1 -ConnectOpenCode -Dev`.
   На Linux/macOS:
   `bash scripts/install.sh --connect-opencode --dev`.
4. При несовместимом конфиге остановись без частичного изменения OpenCode и
   объясни конкретное расхождение. Не ослабляй проверки.
5. Запусти `python scripts/doctor.py` через созданную `.venv`, полный `pytest` и
   `node --test integrations/opencode/token-counter.test.js`, если Node доступен.
6. Не выполняй генерацию. Проверь GET `/models`, здоровье БД/upstream, локальный
   URL и наличие plugin без вывода ключей. Попроси пользователя полностью
   перезапустить OpenCode и самому отправить один новый короткий запрос. После
   этого проверь появление одного события и Session ID в панели.
7. В отчёте укажи корень, URL панели без пароля, команды start/status/stop/rollback
   и результаты PASS/FAIL/NOT TESTED. Не называй mock живой интеграцией.

Если OpenCode не установлен или provider отличается, не создавай выдуманную
конфигурацию. Можно запустить `scripts/install.ps1 -Demo` только для просмотра.
